Description of the library of generated stochastic MCFNDP instances


A generic library of stochastic MCFNDP instances is created with the GenStoch generator based on the following arborescence of configurations. First, subsets of instances are generated under one of two primary topologies: either point-to-point (Section 1) or hubs-and-satellites (Section 2). Second, within each each one these subsets, two further subsets of instances are respectively generated under one of two regimes of distribution of commodity volumes: either one source node and one sink node for each commodity (Sections 1.1 and 2.1), or multiple but identical source nodes and multiple but identical sink nodes for all commodities (Sections 1.2 and 2.2). Within each one of these four subsets, instances are generated according to the flat secondary topology and four further subset result for crossing size of the base instances (smaller or larger) with tightness of capacity in relation to commodity volumes (tighter or looser).  We proceed to describe the exact sets of options and option values appearing in the configurations situated at the leaves of this arborescence.

Remarks:

a- The objective underlying the construction of the library with GenStoch is to exemplify the creation of a moderately diversified set of stochastic MCFNDP instances arising from a limited set of base deterministic MCFNDP instances that would be geared towards the particular goals of a set of computational experiments at hand. The objective is not to perform an expansion from the set of 6000 deterministic instances available in the library of deterministic MCFNDPs by systematically diversifying along the settings available in the stochastic generator. This would be prohibitive in view of the time and storage space that would be required by the large number and large sizes of the base deterministic instances, by the large nummber of settings available in the stochastic generator, and by the heavy computational demands imposed by some of these settings (e.g., large number of scenarios, randomization of several elements of the base deterministic instances).

b- There are 16 base deterministic instances of the MCFNDP originating from the deterministic generator GenDeterm giving rise to the 416 instances of the stochastic MCFNDP included in the library. The library is stored in the /library folder of the repository located at at https://github.com/larseeri/stoch-MCFNDP-gener.

c- The stochastic library rooted at /library has a structure similar to that of the deterministic library rooted at /library in the repository of the determistic generator located at at https://github.com/larseeri/determ-MCFNDP-gener. There is a difference, however: the stochastic library extends this structure by adding terminal subfolders that contain the generated stochastic instances. Thus, the folders of the stochastic library closer to the root can be loaded with deterministic instances and the scripts responsible for generating the stochastic library can refer to the generated stochastic instances and to their base deterministic instances within a common folder structure. It suffices to load the appropriate subfolders of /library with the base determistic instances that are required.

d- Feasibility of each scenario in each instance of the stochastic MCFNDP included in the library has been verified by activating the appropriate option of GenStoch.

e- In view of the very large space that would be required to store all instances of the library, only configuration files are saved. The corresponding MCFNDP instances can be generated from saved configuration files at a high speed using GenStoch while disabling the verification of feasibility of each scenario.

f- Unspecified options are set to their default values.

The generated stochastic MCFNDP instances are saved in the same folder as their founding configuration file.
